# Task Tracker

## О проекте

Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок, меняет статус и находит просроченные записи.

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

После запуска открыть адрес, указанный Vite в терминале.

## Проверка сборки

Остановите dev-сервер через `Ctrl+C`. Выполните в папке `frontend`:

```bash
npm run build
npm run preview
```

## Что работает сейчас

* создан проект React + TypeScript + Vite;
* общий layout с названием приложения и навигацией (React Router, декларативный режим);
* список из 6 демонстрационных задач с повторно используемой карточкой `TaskCard`;
* страница подробностей задачи, выбираемой по id из адреса;
* страница-заглушка создания задачи;
* отдельные страницы для неизвестного адреса и отсутствующей задачи;
* строгая проверка типов TypeScript и production-сборка.

## Адреса страниц

| Адрес | Страница |
|---|---|
| `/` | перенаправление на `/tasks` |
| `/tasks` | список задач |
| `/tasks/:id` | подробности задачи (например, `/tasks/t1`) |
| `/tasks/new` | заглушка создания задачи |
| любой другой | «Страница не найдена» |

Если задачи с указанным id нет (например, `/tasks/missing`), показывается сообщение «Задача не найдена».

Все записи **демонстрационные**: они вымышлены и хранятся в `frontend/src/data/tasks.ts`.
